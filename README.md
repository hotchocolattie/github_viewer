# GitHub Viewer

A React web app for browsing a GitHub user's public repositories. Search by username, filter repositories, sort by name or stars, and open repository or profile links directly on GitHub!

## Run Locally

1. Clone repository
  
3. From the repository root:

```bash
cd viewer
npm install
npm start
```

3. Open [http://localhost:3000](http://localhost:3000)!

## Using the App

1. Enter a GitHub username.
2. Press enter or click explore to fetch the user's public repositories.
3. Use the search field to filter by repository name, description, or language.
4. Use the sort menu to order repositories by stars or name.
5. Click a repository name or the username to open its GitHub page.
6. Click a long description to expand or collapse it.

The header can be collapsed with the three-line shelf control. When scrolling through the repository list, the shelf remains available at the top of the page, so you can search up another name fast.
